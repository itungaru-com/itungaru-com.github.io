# ITUNGARU individual SVG assets

These are **new, simplified vector interpretations**, not exact vectorizations of the approved detailed image-generation concepts. Each SVG is a separate transparent asset.

Files: logo-light.svg, logo-dark.svg, wordmark-light.svg, wordmark-dark.svg, shark-tooth.svg, favicon.svg, wave.svg, wave-border.svg, woven-border.svg, tooth-border.svg, frigatebird.svg, canoe.svg.

Use `<img src="/brand/shark-tooth.svg">` after copying files into `static/brand/`.

The single-color decorative SVGs use `currentColor`, which can default to black in `<img>` contexts; for easy CSS recoloring inline the SVG markup or replace `currentColor` with a hex value.

Cultural note: woven/tooth patterns and canoe are stylized modern motifs, not verified historical Kiribati reproductions. Review before claiming historical authenticity.
